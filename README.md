# FlowGate.Portal

Frontend da plataforma FlowGate - SPA em Angular.

## Stack
- Angular 19+
- TypeScript
- SCSS
- Docker + nginx

## Rodando localmente

### Pre-requisitos
- Node.js 22+
- Backend rodando em http://localhost:8080 (ou via Docker em FlowGate.Infra)

### Comandos
```bash
npm install
npm start
```
App disponivel em: http://localhost:4200

### Build para producao
```bash
npm run build
```
